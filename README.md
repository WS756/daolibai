# 倒立摆控制器（J280 姿态控制系统开发套件）

基于《J280姿态控制系统开发套件介绍手册》第 6 章的**位置式离散 PID**，用 Verilog
实现的倒立摆控制器（器件 `GW2A-LV55PG484C8/I7`，引脚与 FPGA1 工程一致）。

实现三个任务：
1. **稳摆**：摆杆直立、摆臂停在原点；
2. **匀速转圈**：摆杆保持直立，摆臂匀速旋转；
3. **转一圈**：按一下按键，摆臂转整整一圈后停住。

> 本工程不含自动起摆，需手动把摆杆扶到直立附近再启动。

---

## 1. PID 公式（手册 6.3）

位置式离散 PID：

```
PWM = Kp * e(k) + Ki * Σe(k) + Kd * [ e(k) - e(k-1) ]
```

- `e(k)`：本次偏差
- `e(k-1)`：上次偏差
- `Σe(k)`：偏差累计和
- `Kp / Ki / Kd`：比例 / 积分 / 微分参数（Q8 定点，真实值 = 参数 / 256）

## 2. 控制结构（串级 + 速度阻尼）

```
位置环(外环,纯P): 目标位置 - 编码器位置 ──> 倾角偏移 tilt
目标倾角 = 直立角 + tilt
倾角环(内环,PD): 目标倾角 - 摆杆角度(ADC) ──> 电机 PWM
摆臂速度阻尼: -ARM_DAMP * 摆臂速度 ──────────> 直接加到电机指令
```

- **位置环**：摆臂偏离原点时，让摆杆朝原点方向轻微倾斜；
- **倾角环**：追踪目标倾角，保持摆杆直立，同时驱动摆臂回原点/旋转；
- **速度阻尼**：直接加到电机指令，防止摆臂越转越快、减小过冲。

## 3. 按键与任务

| 按键 | 静止时 | 运行中 |
|---|---|---|
| SW1 | 启动稳摆（任务一） | — |
| SW2 | 校准直立角度 | 转一圈（任务三） |
| SW3 | — | 切换匀速转圈（任务二，开/关） |
| SW4 | 停止 | 停止 |

- **任务一（稳摆）**：SW1 启动，摆杆直立、摆臂停在启动瞬间的位置；
- **任务二（匀速转圈）**：运行中按 SW3 开始匀速转圈，再按 SW3 停止；
- **任务三（转一圈）**：运行中按 SW2，摆臂匀速转 360° 后停住（末尾自动减速）。

## 4. 使用步骤

1. 用 Gowin IDE 打开 `pendulum.gprj`，综合 + 布局布线 + 下载（SRAM）。
2. 复位，等 1 秒让摆杆自然下垂静止。
3. 把摆杆扶到直立，按 **SW2** 校准（锁存当前角度为直立目标）。
4. 仍扶住摆杆，按 **SW1** 启动，慢慢松手。
5. 按 **SW3** 测匀速转圈，按 **SW2** 测转一圈，**SW4** 停止。
6. 摆杆掉出稳摆区约 100ms 会自动停止，防止电机失速。

## 5. 参数（`pendulum_ctrl.v`）

| 参数 | 默认值 | 含义 |
|---|---|---|
| ANG_KP | 384（=1.5） | 倾角环比例 |
| ANG_KI | 0 | 倾角环积分（关） |
| ANG_KD | 3072（=12.0） | 倾角环微分阻尼 |
| POS_KP | 32（=0.125） | 位置误差 → 倾角偏移 |
| POS_KI | 0 | 位置环积分（关） |
| ARM_DAMP | 64 | 摆臂速度阻尼（直接乘速度） |
| ONE_REV | 1040 | 一圈的编码器计数 |
| ROTATE_STEP | 1 | 转圈步长（每 2 拍 1 步 ≈ 0.25 圈/秒） |
| DECEL_COUNTS | 200 | 转一圈末尾减速段（最后 200 计数半速） |
| ANGLE_SETPOINT | 2925 | 默认直立角度（12 位扩展计数） |
| ANGLE_POLARITY | +1 | 倾角环输出极性 |
| OUT_LIMIT | 120 | 电机指令总限幅（PWM） |
| POS_OUT_LIMIT | 150 | 倾角偏移上限（角度计数） |
| FALL_ANGLE / FALL_TICKS | 1500 / 50 | 脱落检测阈值 / 周期 |

**转圈方向反了**：把 `ROTATE_STEP` 和 `ONE_REV` 都取负。

## 6. 文件结构

| 文件 | 说明 |
|---|---|
| `src/pendulum_ctrl.v` | 串级控制器 + 三任务状态机 |
| `src/pid_position.v` | 位置式 PID 核心（手册公式，Q8，抗积分饱和） |
| `src/adc.v` | 3PA1030 10 位并行 ADC（2ms 采样节拍） |
| `src/encoder.v` | 霍尔正交编码器 4 倍频解码 |
| `src/motor_driver.v` | TB6612FNG 驱动（20kHz PWM） |
| `src/key_filter.v` | 按键消抖 |
| `src/top.v` | 顶层，引脚与 FPGA1 一致 |
| `src/pendulum.cst` / `src/timing.sdc` | 引脚 / 时序约束 |
| `src/uart_tx.v` / `src/telemetry.v` | 调试串口 |
| `pendulum.gprj` | Gowin 工程文件 |
| `sim/tb_pid_position.v` | PID 自检测试台 |

## 7. 调试

- **LED**：LED0 稳摆中；LED1 ADC 角度活度；LED2 电机有输出；LED3 心跳。
- **串口**：115200 8N1，每 20ms 一帧 12 字节：
  `AA 55 angle_H angle_L err_H err_L perr_H perr_L cmd_H cmd_L run 0A`

## 8. 注意事项

- 控制周期 2ms（500Hz）。
- 不同设备 ADC 下垂初始值有差异；若你的板子直立角度不是 2925，修改 `ANGLE_SETPOINT`。
- 若按下 SW1 摆杆反而加速倒下，把 `ANGLE_POLARITY` 取反。
