# 倒立摆 PID 控制器（J280 姿态控制系统开发套件）

基于《J280姿态控制系统开发套件介绍手册》第 6 章的**位置式离散 PID** 与
**两环叠加**控制结构，用 Verilog 重新实现的倒立摆稳摆工程（器件
`GW2A-LV55PG484C8/I7`，引脚与 FPGA1 工程一致）。

> 本工程只做 PID 稳摆，**不含自动起摆**。使用方法是：复位后用手把摆杆扶到
> 直立附近，按 SW1 启动稳摆，SW4 停止。

---

## 1. 核心算法（严格取自手册 6.3）

位置式离散 PID：

```
PWM = Kp * e(k) + Ki * Σe(k) + Kd * [ e(k) - e(k-1) ]
```

- `e(k)`：本次偏差
- `e(k-1)`：上次偏差
- `Σe(k)`：偏差累计和
- `PWM`：输出
- `Kp / Ki / Kd`：比例 / 积分 / 微分参数

控制结构（手册 6.4 框图）：

```
目标角度 --→ [倾角环 PID] -- PWM_angle --┐
                                          ├--(叠加)→ 电机PWM → TB6612 → 电机
目标位置 --→ [位置环 PID] -- PWM_pos  ----┘
               ↑ 编码器位置 / 速度
```

- **倾角环**：目标角度 vs 摆杆角度（WDD35D4 角位移传感器 → ADC）→ `PWM_angle`
- **位置环**：目标位置 vs 摆臂位置（霍尔编码器，含速度阻尼）→ `PWM_pos`
- 两者相加，限幅后输出给 TB6612。

## 3. 定点约定（重要）

- 所有增益 `KP / KI / KD` 均为 **Q8 定点**：真实增益 = 参数值 / 256。
  例：`KP = 256` 表示 1.0；`KD = 4096` 表示 16.0。
- 输出 `command` 为有符号 PWM 计数（±120），交给电机驱动模块决定方向与占空比。
- 控制周期 **2ms**（500Hz），由 `adc` 模块的 `sample_valid` 提供。

## 4. 默认参数与整定

| 参数 | 默认值 | 含义 |
|---|---|---|
| `ANG_KP` | 128（=0.5） | 倾角环比例（起步值） |
| `ANG_KI` | 0 | 倾角环积分（先关） |
| `ANG_KD` | 256（=1.0） | 倾角环微分（起步值） |
| `POS_KP` | 0 | 位置环比例（先关） |
| `POS_KI` | 0 | 位置环积分 |
| `POS_KD` | 0 | 位置环微分/速度阻尼（先关） |
| `ANGLE_SETPOINT` | 2925 | 直立角度（12 位扩展计数） |
| `ANGLE_POLARITY` | -1 | 倾角环输出极性（+1 / -1） |
| `OUT_LIMIT` | 120 | 电机指令限幅 |

**上电排查（按顺序做，先确认方向再谈稳定）：**

1. 重新综合 + 重新下载，确认用的是新 bitstream（旧位流不会生效）。
2. 用手把摆杆扶到直立，按 **SW2** 校准（把当前角度存为直立目标），再按 SW1，**别松手**：慢慢把摆杆往一边倾一点点，看摆臂/电机往哪边转。
   - 正确：摆臂往"把摆杆扶回直立"的方向转（顶着你的手）。
   - 错误：摆臂往"让摆杆更倒"的方向转 → 把 `ANGLE_POLARITY` 取反（`-16'sd1` ↔ `16'sd1`）。
3. 方向对了再松手试：能短暂直立即可；若来回晃就调 `ANG_KD`（先 256 → 512 加阻尼）。
4. 直立稳定后再开位置环：先 `POS_KD`（速度阻尼，如 128~256），再 `POS_KP`（回中，如 32~64）。

**符号方向：** 反馈方向取决于机械安装（电机转向、编码器极性、电位器方向）。
角度环方向用 `ANGLE_POLARITY` 翻；位置环方向用 `POS_KP / POS_KD` 的符号翻。

## 5. 使用与下载

1. 用 Gowin IDE 打开 `pendulum.gprj`，综合 + 布局布线 + 下载（SRAM）。
2. 复位，等待 1 秒让摆杆自然下垂静止。
3. 用手把摆杆扶到直立，按 **SW2** 校准：把当前角度锁存为直立目标。
4. 仍扶住摆杆，按 **SW1** 启动稳摆，慢慢松手。
5. **SW4** 停止；摆杆掉出稳摆区约 100ms 会自动停止，防止电机失速。

**LED 指示：** LED0 稳摆中；LED1 角度误差方向；LED2 电机有输出；LED3 心跳。

**调试串口：** 115200 8N1，每 20ms 一帧 12 字节：
`AA 55 angle_H angle_L err_H err_L perr_H perr_L cmd_H cmd_L run 0A`
其中 `angle` 为 12 位角度（直立约 2925，视机械而定），`err/perr` 为角度/位置误差，
`cmd` 为有符号电机指令。

## 6. 注意事项

- 手册提到不同设备的 ADC 下垂初始值有差异（建议 990~1040，10 位量程）。若你的
  板子直立角度不是 2925（12 位扩展值），修改 `ANGLE_SETPOINT` 即可。
- 本工程未在本机做过综合/实机验证（本机无 Gowin 工具）；下载后需按第 4 节实机整定。
- PID 模块可用 iverilog 仿真验证：
  `iverilog -o tb -s tb_pid_position src/pid_position.v sim/tb_pid_position.v && vvp tb`
